# The Hypotenuse Calculator

## Description
It asks you what is the length of side a and b and then calculates the hypotenuse

## How to run
You press the run program button

## Input needed
You then need to enter the length of side A and side B

## Example
Enter side a and b to calculate the hypotenuse
enter side a: 21
enter side b: 42
the hypotenuse is:46.95
